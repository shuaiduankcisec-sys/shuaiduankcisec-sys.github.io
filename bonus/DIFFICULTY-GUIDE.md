# 补题流程与难度评分量化规范（DIFFICULTY-GUIDE）

> 目的：让任何 agent（包括低阶模型）都能**无错**地补充题目、并给每道题打一个**真实可信**的难度。
> 核心思想：难度不再是"感觉"，而是**5 个可独立验证的是非题**逐项打分累加。
> 本文档是唯一权威标准；写题和评分都必须严格照做，禁止凭感觉。

---

## 一、难度评分：5 项是非打分法（每条 1 分，1 分 = 1 星）

对一道题，回答下面 5 个"是/否"问题，每答一个"是"记 1 分。**最终难度 = 1 + 得分**（范围 1–5 星）。

> 说明：题目至少 1 星打底，故难度 = 1 + 五题得分。得 0 分 → 1 星；得 4 分 → 5 星。

### 五个评分问题（必须逐条回答）

| # | 问题 | 判"是"的明确标准 | 常见反例（判"否"） |
|---|---|---|---|
| Q1 | **是否需要"构造"或"洞察"，而非直接套公式？** | 需要主动引入一个量/换元/辅助线/函数形式，或需要看出一个隐藏结构 | 直接代入余数定理、直接求导、直接套韦达、直接裂项求和 |
| Q2 | **是否包含 2 个及以上独立子任务（(i)(ii)(iii) 或"hence/deduce"延伸）？** | 题干明确分了多个小问，或要求"证明 A 并用它求 B" | 单一问题、单一计算 |
| Q3 | **是否用到"高级技巧"（非 A-Level 基础标配）？** | 归纳法、反证法、递推、参数方程、隐函数、向量叉积/三重积、夹逼、对称性代换、分部积分、双换元、单调有界收敛 | 加减乘除、一次代入、直接展开、求基本导数 |
| Q4 | **解法是否 ≥4 个实质步骤（每个步骤都改变数学对象）？** | 把解法按"换行 + 衔接词(hence/then/so/therefore)"切成独立步骤，数出 ≥4 步 | 1–3 步直接出答案 |
| Q5 | **是否需要"证明/说明理由"，而非只"算出结果"？** | 题干含 prove / show that / justify / explain / deduce / state and prove | 只需 find / solve / evaluate 一个数值 |

### 评分判定表（对照读）

| 得分 | 难度 | 一句话画像 |
|---|---|---|
| 0 | ★☆☆☆☆ 1星 | 套一个公式直接出答案 |
| 1 | ★★☆☆☆ 2星 | 一个标准技巧，1–3 步 |
| 2 | ★★★☆☆ 3星 | 标准但需细心/一个技巧+几步 |
| 3 | ★★★★☆ 4星 | 多子任务，或需构造/洞察，多步 |
| 4 | ★★★★★ 5星 | 需要非平凡构造或深刻证明，多步+高级技巧 |

### 硬性规则（必须遵守）

1. **禁止"看来源给难度"**：STEP 题也有 1–2 星，TMUA/MAT 题也有 4 星。难度只由上面 5 题决定。
2. **禁止"看题干长度给难度"**：题干长≠难。长题干但只套公式 = 低星。
3. **禁止"看解法行数给难度"**：有人把 2 步写 10 行。判断的是**实质步骤数**，不是换行数。
4. **Q4 的"步骤"定义**：一个步骤必须**改变数学对象**（例如：换元后变成新变量、分部后消去一项、求导后得到新表达式）。单纯抄写、注释、验算不计数。
5. **低于 3 星（得分 ≤1）的题不得进入题库**：补题时若算出 ≤2 星，说明这题太基础，应换更难的题，而不是硬标 3 星。

## 二、评分示例（正反例对照，必须读懂再写题）

### ✅ 正确示例

**例 A**：`f(x)=x³−6x²+11x−6`，证明 x−1 是因式并完全分解。
- Q1 构造/洞察？否（直接代入 f(1)）
- Q2 多子任务？否
- Q3 高级技巧？否（因式分解是基础）
- Q4 ≥4 步？否（2 步）
- Q5 需证明？是（show that）
- 得分 1 → **2 星**（低于 3 星，不得入库）

**例 B**：`x³+y³=6xy`（folium），求 dy/dx 并求 x=y 处的点。
- Q1 否、Q2 是（两问）、Q3 是（隐函数求导）、Q4 是、Q5 否
- 得分 3 → **4 星** ✅

**例 C**：证明 `cos 3θ=4cos³θ−3cosθ` 并用它解 `4x³−3x=½`。
- Q1 是（看出 cos3θ 结构）、Q2 是（两问）、Q3 否、Q4 是、Q5 是
- 得分 4 → **5 星** ✅

### ❌ 错误示例（上一轮真实犯过的错）

| 题 | 当时误标 | 正确 | 错因 |
|---|---|---|---|
| 求 d/dx(x^x) | 4 星 | 2 星 | 只 Q3（对数求导）命中，得分 1 |
| 切线长 =√(OP²−r²) | 4 星 | 1 星 | 直接套公式，5 题全否，得分 0 |
| 解 (ln x)²−ln x−2=0 | 4 星 | 2 星 | 换元是基础，只 Q1 命中，得分 1 |
| 因式分解 x³−6x²+11x−6 | 4 星 | 2 星 | 直接代入，只 Q5 命中 |

## 三、补题标准流程（低阶 agent 照做）

### 步骤 1：选题
- 优先 STEP（用户指定）。每章目标难度 ≥3 星。
- **选题前先问自己**：这题用 5 题打分能否 ≥3 星？不能就换更难的。

### 步骤 2：写题（严格字段格式）
题目 JSON 字段（缺一不可）：
```
id          → 章节前缀 + 递增序号，如 ch01-012 或 A2-03-011
chapter     → AS 用数字(1-12)，A2 用字符串("A2-01"~"A2-09")
title       → ""（空）
source      → "STEP" / "TMUA" / "MAT" / "ESAT" / "Original"
paper       → 如 "STEP I" / "STEP II"
year        → 数字
sourceUrl   → "https://step.maths.org/questions"
solutionUrl → ""
level       → "AS" 或 "A2"（必须与 chapter 匹配）
difficulty  → 按本规范打分（1-5 整数）
topics      → 数组，2-4 个短语
methods     → 数组，2-4 个动名词短语（用于考试局过滤，必须准确）
statement   → LaTeX 题干（$...$ 行内，$$...$$ 显示）
solution    → LaTeX 完整解法
solutionStatus → "full"
hints       → 数组，2-4 条提示
```

### 步骤 3：写难度注释（强制）
每道题**必须在 solution 里用一句话注明评分依据**，格式：
```
[难度自评: Q1否 Q2是 Q3是 Q4是 Q5否 → 3星]
```
> 这是低阶 agent 无错的关键：强制它把 5 题打分显式写出来，评审者一眼可核对。

### 步骤 4：跑校验（必须全部通过）
```bash
cd bonus
node build-index.js        # 重新生成 index.json
node validate.js            # 数据完整性校验，必须 0 错误
python verify_answers.py    # sympy 独立验证答案，必须全通过
node score-difficulty.js    # 用词法规则复核难度，人工核对偏差
```

### 步骤 5：提交
```bash
git add bonus/ && git commit -m "题库：新增 N 道 [来源] 题（难度 X-Y 星）"
```

## 四、LaTeX 与 JSON 关键陷阱（低阶 agent 必看，否则必错）

1. **反斜杠必须双写**：JSON 里 LaTeX 的每个 `\` 要写成 `\\`。
   - 正确：`"statement": "... $\\sqrt{2}$ ..."`（磁盘上是 `\\`，解析后是 `\`）
   - 错误：`"$ \sqrt{2} $"`（单反斜杠 → JSON 非法转义，build-index 直接崩）
   - **实用技巧**：用 Write 工具写文件时，参数里每个反斜杠写 4 个（`\\\\`），落盘才正确。
2. **写完必须立即跑 build-index**：非法转义只会在这一步暴露，早跑早发现。
3. **幂/下标的 LaTeX**：`x^{2}`、`x_{n}`、`\frac{a}{b}`、`\sqrt{x}`、`\int_{0}^{1}`。
4. **AS 与 A2 边界**：AS（第 1-12 章）不得出现链式/乘积/商法则、对数/隐函数求导、换元/分部积分（见 exam-boards.json 的 oxford-aqa AS 排除清单）。A2 无此限制。
